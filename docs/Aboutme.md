# Projects

## 1. E-Commerce Platform

A lightweight client-side e-commerce web application built using HTML, CSS, and JavaScript. This project fetches product data from the DummyJSON API and delivers a complete shopping browsing experience without requiring build tools or external dependencies.

### Key Highlights
- Responsive product listing in a grid layout
- Pagination with 8 products per page
- Real-time search with autocomplete suggestions
- Dedicated product details page
- Visit history tracking with timestamps
- Persistent search and visit history using localStorage
- Mobile-friendly responsive design

### Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript (ES6+)
- DummyJSON API
- Browser localStorage

### What I Learned
This project helped me strengthen my understanding of DOM manipulation, API integration, local storage handling, responsive design, and structuring multi-page frontend applications using vanilla JavaScript.

## 2. NeoExpense — MERN Stack Expense Tracker

A full-stack MERN expense tracker application developed with MongoDB, Express.js, React.js, and Node.js. It features a rich skeuomorphic dark UI and allows users to manage expenses efficiently through a complete CRUD-based workflow.

### Key Highlights
- Add, edit, delete, and view expenses
- Dashboard with spending statistics and visual charts
- Expense categorization with color-coded icons
- Filtering by category, date range, and sorting options
- Doughnut chart for category-wise spending
- Bar chart for monthly expense trends
- Responsive design for desktop and mobile
- Toast notifications for user actions

### Tech Stack
- MongoDB
- Express.js
- React.js
- Node.js
- Vite
- Chart.js
- Axios
- react-hot-toast
- react-icons

### Live Project
- [NeoExpense Dashboard](https://neoexpense-dashboard.vercel.app/)

### What I Learned
This project improved my understanding of full-stack application architecture, REST API development, MongoDB integration, state management using Context API, data visualization, and communication between frontend and backend systems.
