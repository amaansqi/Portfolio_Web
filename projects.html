E-Commerce Platform

A lightweight client-side e-commerce web application built using HTML, CSS, and JavaScript. Fetches product data from the DummyJSON API and delivers a complete shopping browsing experience without requiring build tools or external dependencies.

Key Features

  • Responsive product listing in a grid layout
  • Pagination with 8 products per page
  • Real-time search with autocomplete suggestions
  • Dedicated product details page
  • Visit history tracking with timestamps
  • Persistent search & visit history via localStorage
  • Mobile-friendly responsive design

What I Learned

  • DOM manipulation at scale
  • API integration and async data fetching
  • LocalStorage handling for persistence
  • Responsive design patterns
  • Multi-page frontend architecture

Type — Full-Stack Stack — MERN Status — Live

NeoExpense

A full-stack MERN expense tracker application featuring a rich skeuomorphic dark UI. Users can manage expenses through a complete CRUD-based workflow with dashboard statistics, visual charts, and category-based filtering.

Key Features

  • Add, edit, delete, and view expenses
  • Dashboard with spending statistics and visual charts
  • Expense categorization with color-coded icons
  • Filtering by category, date range, and sorting
  • Doughnut chart for category-wise spending
  • Bar chart for monthly expense trends
  • Responsive design for desktop and mobile
  • Toast notifications for user actions

What I Learned

  • Full-stack application architecture
  • REST API development
  • MongoDB integration and data modeling
  • State management using Context API
  • Data visualization with Chart.js
  • Frontend-backend communication
