## 🎨 About

This is a personal portfolio website showcasing projects, skills, and contact information. The portfolio is fully responsive, featuring smooth animations and a modern design that works seamlessly across all devices.

## ✨ Features

- **Responsive Design** - Mobile-first approach with CSS media queries
- **Smooth Animations** - CSS and JavaScript-powered animations
- **Clean Navigation** - Intuitive navbar for easy navigation
- **Project Gallery** - Grid layout showcasing featured projects
- **Contact Form** - Easy way for visitors to get in touch
- **Modern UI/UX** - Contemporary design with smooth transitions
- **GitHub Pages Ready** - Deployed and accessible online

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- No server or build tools required - this is a static website

### Installation

1. Clone the repository:
```bash
git clone https://github.com/amaansqi/Assignment1.git
cd Assignment1
```

2. Open in your browser:
```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

Or simply double-click `index.html` to open in your default browser.

## 📱 Responsive Design

The portfolio is fully responsive with breakpoints for:

- **Desktop** (≥1024px) - Full desktop experience
- **Tablet** (768px - 1023px) - Optimized tablet layout
- **Mobile** (≤767px) - Mobile-optimized interface

All layouts adapt smoothly to different screen sizes ensuring excellent user experience across all devices.
